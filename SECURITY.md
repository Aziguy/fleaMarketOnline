# Politique de sécurité

## Signaler une vulnérabilité

Ne créez **pas** d'issue publique. Utilisez le [signalement privé de GitHub](https://github.com/Aziguy/fleaMarketOnline/security/advisories/new) en indiquant :

- la description du problème et son impact ;
- les étapes pour le reproduire ;
- la version ou le commit concerné.

Vous recevrez une réponse sous 7 jours. Une fois le correctif publié, la vulnérabilité sera documentée et votre contribution créditée si vous le souhaitez.

## Versions prises en charge

Seule la branche `master` reçoit des correctifs de sécurité.
