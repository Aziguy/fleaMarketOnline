## Pensée pour le mall et pour Yaoundé

<CardGrid stagger>
  <Card title="Paiement sur place" icon="seti:pipeline">
    Aucun paiement en ligne. Espèces, MTN Mobile Money ou Orange Money, devant le commerçant ou le livreur.
  </Card>
  <Card title="Prix en FCFA" icon="document">
    Montants entiers en Franc CFA, promotions avec ancien prix barré.
  </Card>
  <Card title="Retrait ou livraison" icon="rocket">
    Code de retrait à 6 chiffres en boutique, ou livraison payée à la réception.
  </Card>
  <Card title="WhatsApp" icon="comment">
    Chaque boutique joignable en un clic, panier envoyé pré-rempli.
  </Card>
  <Card title="Réservations" icon="information">
    Rendez-vous pour les salons, tables pour les restaurants et les bars.
  </Card>
  <Card title="Mobile d'abord, FR / EN" icon="translate">
    Pages légères, application installable et consultable hors ligne, thème clair ou sombre.
  </Card>
  <Card title="En direct" icon="rocket">
    Les commerçants voient arriver commandes et réservations sans recharger la page.
  </Card>
  <Card title="Assistant IA et API" icon="puzzle">
    Descriptions produits rédigées par Claude, recherche élargie, API REST documentée.
  </Card>
</CardGrid>
